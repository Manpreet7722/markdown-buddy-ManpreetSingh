I reviewed and verified the generated content before including it in my submission. All final calculations are performed independently in R. I am responsible for the accuracy and originality of this work.

Reflection Questions
Question 1: How did AI support your documentation process?

AI supported my documentation process by helping me organize the project into logical sections and identify common elements of a professional GitHub README.

The initial prompt helped identify sections such as an overview, installation instructions, usage examples, dataset information, project structure, analysis process, and licensing information. Refinement prompts helped make the structure more concise and consistent with Markdown formatting.

AI was particularly useful for generating ideas about how information could be organized. It suggested separating the project overview, dataset description, analysis process, installation instructions, example code, outputs, verification process, limitations, and AI disclosure.

However, I did not treat the generated content as automatically correct. I reviewed the content and adapted it to the specific requirements of the BDA400 assignment.

The main benefit was that AI provided a starting point for the documentation structure while I remained responsible for reviewing and editing the final material.

Question 2: What were the strengths and weaknesses of using AI for this assignment?

One strength of using AI was its ability to quickly generate a structured starting point. Creating documentation from a blank page can take time, while AI can provide an initial organization that can then be reviewed and improved.

Another strength was formatting assistance. AI suggested appropriate Markdown headings, bullet lists, tables, and code blocks. This helped create a consistent README structure.

AI also helped identify areas that should be documented, such as installation, dependencies, inputs, outputs, limitations, and verification.

There were also weaknesses.

AI-generated information can be incorrect or too generic. A generated README may contain assumptions about a project that are not actually true. For this reason, I reviewed the content rather than accepting it without checking.

Another weakness is that AI does not know the exact requirements of a project unless sufficient information is provided. Generic recommendations therefore needed to be adapted to this assignment.

AI-generated calculations should also not automatically be trusted. The assignment requires students to perform calculations independently. Therefore, I used R to perform the calculations rather than relying on AI to provide numerical results.

Overall, AI was useful as a documentation assistant, but human review and verification remained necessary.

Question 3: How did you ensure ethical and accurate use of AI?

I followed several practices to use AI responsibly.

First, I disclosed the use of ChatGPT in the required AI Assistance Declaration. I included the tool, model, date, purpose, and major prompts used during the documentation process.

Second, I did not provide real personal or confidential information to the AI tool. The project uses synthetic data, which follows the assignment requirements.

Third, I manually reviewed the generated Markdown and R Markdown content. I checked headings, lists, tables, code blocks, and the overall organization.

Fourth, I independently performed the calculations in R. AI was not used as the source of the final numerical results.

Fifth, I used a verification process consisting of a primary calculation, an independent cross-check, and a spot-check. This helped reduce the possibility of calculation errors.

Finally, I previewed the documentation before considering it complete. This helped identify formatting or organizational problems.

The main lesson I learned is that generative AI can be useful when treated as an assistant rather than an authority. The student remains responsible for checking the accuracy, originality, and appropriateness of the final work.
